# 十二の季節

小さな村を預かり、十二ヶ月を生きのびるドット絵のストラテジー。1 プレイ約 10 分。

- 8×8 のマップに家・畑・井戸・祠を建て、村人に仕事を割り振る
- 毎月ひとつ、2 択の出来事が起きる
- 秋に蓄えて、食事が倍になる冬を越せるかが勝負
- 終了時にマップのポストカード(PNG)を保存できる

## 開発

```sh
npm install
npm run dev     # 開発サーバー
npm test        # ルールのテスト(シミュレーション含む)
npm run build   # 型チェック + 本番ビルド
```

構成: `src/game.ts`(ルール) / `src/events.ts`(出来事カード) / `src/sprites.ts`(ドット絵) / `src/ui.ts`(画面)
